# 项目规则（AGENTS.md）

本文件是本项目的编码规则，所有 AI 助手与开发者在新建 / 修改文件时必须遵守。

## 0. 语言约定

- 所有说明文字、文档、检查清单条目一律使用**简体中文**。
- 文件路径、HTML / CSS / JS 标识符（类名、id、变量名、函数名等）**保留英文原文**，不作翻译。
- 后续在本项目中生成的任何文档、检查清单均遵守此约定。

## 1. 命名规则

- 所有 CSS 类名、id 名、JS 变量名一律以 `ysw_` 开头（例如 `ysw_nav-bar`、`ysw_total`）。
- 例外：使用第三方模板 / 官方 starter 中已给定的 id、class 时保持原名，不得擅自改名，以保证与目标效果还原对照。

## 2. 页面结构规则

- 新建的每个 HTML 文件必须加入指向首页的超链接：`<a href="index.html">返回首页</a>`。

## 3. 新建 HTML 文件的注释规则（重要）

新建 HTML 文件时，必须编写注释，尤其是 JS 部分：每个函数均需注释其主要功能实现方式。注释内容必须包含以下四项：

1. **作者**：尹松旺
2. **建立时间**：文件创建的日期时间（精确到日期即可，格式 `YYYY-MM-DD`）
3. **使用模型**：完成该文件所使用的 AI 模型名称
4. **功能名称及简介**：函数名 + 该函数做了什么、用了什么方法实现

文件头部注释模板：

```html
<!--
  文件名称：xxx.html
  作    者：尹松旺
  建立时间：YYYY-MM-DD
  使用模型：GLM-5.3-Flash
  功能简介：（一句话说明页面用途与核心技术点）
-->
```

JS 函数注释模板：

```js
/* 函数名：ysw_renderXxx
 * 作者：尹松旺  建立时间：YYYY-MM-DD  使用模型：GLM-5.3-Flash
 * 功能简介：一句话说明该函数的功能与实现方法（如"reduce 累加求总分并渲染统计卡"）
 */
```

## 4. 提示词记录规则

- 用户发给 AI 的每一条提示词，必须在执行之前以**追加**方式写入 `ysw_prompt.md`（不覆盖历史内容），内容包括：时间、使用的模型、提示词内容。
