💬 与 AI 的提示词对话记录（任务一）

👤 第 1 轮提示词（我） 请帮我用 Swiper 初始化一个轮播 #wySw4，要求：① 不要循环 ② 3.2 秒自动翻页，用户操作后不要停 ③ 底部小圆点可以点击跳转 ④ 初始切换效果是 cube 立方体。
🤖 AI 第 1 轮回答 好的，这是配置： 
var swiper = new Swiper('#wySw4', {
    loop: true,
    effect: 'cube',
    autoplay: { delay: 3200 },
    pagination: { el: '.swiper-pagination' }
});
👤 第 2 轮提示词（我纠正） 你给的代码有三处错误：① 我明确说"不要循环"，你写了 loop: true，应改为 loop: false 或不写；② autoplay 缺 disableOnInteraction: false，用户操作后自动播放会停止；③ pagination 缺 clickable: true，圆点不可点击。请用正确参数重写，并把分页器 el 改为 #wyPag4。
🤖 AI 第 2 轮回答（修正后） 抱歉，已修正： 
var swiper = new Swiper('#wySw4', {
    loop: false,
    effect: 'cube',
    autoplay: { delay: 3200, disableOnInteraction: false },
    pagination: { el: '#wyPag4', clickable: true }
});
✅ 验证结论 第 2 轮代码粘进页面后全部满足：无循环（最后一张不能再往后翻）、3.2s 自动翻页、拖动后不停、圆点可点击跳转、cube 3D 效果。

💬 与 AI 的答疑记录（任务二）

👤 提问 Swiper 的 creativeEffect 里 prev.transform 和 next.transform 分别控制什么？百分比是相对谁的？
🤖 AI 回答 creativeEffect.prev 控制上一张（当前 slide 左侧）的样式，next 控制下一张（右侧）。transform 是数组 [x, y, z]，单位可以是 px 或百分比字符串（如 '-30%'）。百分比是相对于当前 slide 自身的宽高计算的：x 方向的 % 相对 slide 宽度，y 方向相对 slide 高度。z 只能是 px（3D 深度）。
👤 提问 怎么让卡片旋转 20 度？
🤖 AI 回答 在 prev 或 next 对象里加 rotate: 20（单位是度）。例如 next: { translate: ['60%', 0, -100], scale: 0.85, rotate: 20 } 就能让右侧的下一张卡片倾斜 20 度。改数值后 Swiper 会自动应用。

💬 与 AI 的关键对话（任务三）

👤 提问 我想给 Swiper 加键盘左右方向键控制，怎么写？
🤖 AI 回答 在配置里加 keyboard: { enabled: true, onlyInViewport: true }。enabled 开启键盘，onlyInViewport 表示只有轮播在可视区域内时才响应键盘（避免页面上多个轮播同时响应）。用户需要先点击轮播区域让它获得焦点。

🎤 答辩四连问答案

  1. 这段代码什么意思？ keyboard: { enabled: true, onlyInViewport: true } 开启键盘控制，仅当轮播在视口内且获得焦点时响应左右方向键。
  2. AI 第一次给的哪里不对？ AI 只给了 keyboard: true，缺少 onlyInViewport，页面多个轮播会冲突；已补上。
  3. 你改了什么？新参数作用？ 改为对象形式并加 onlyInViewport: true，限制只有当前可见轮播响应键盘。
  4. 现场改 delay： autoplay.delay 改成 1500 → 每张停留 1.5 秒，翻页更快；改成 5000 → 每张停留 5 秒，翻页更慢。
